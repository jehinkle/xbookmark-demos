Derive ADTTE with censoring rules

This guide shows how to build a progression-free survival (PFS) parameter in an ADTTE dataset, with event and censoring sources defined explicitly so that reviewers can trace every date back to the SAP.

1. Define event and censoring sources

Each source names the dataset, the filter that selects qualifying records, and the date to use.

pd <- event_source(
  dataset_name = "adrs",
  filter = PARAMCD == "PD",
  date = ADT
)
lastvisit <- censor_source(
  dataset_name = "adrs",
  filter = PARAMCD == "LSTA",
  date = ADT
)
Note: The censoring date must match the rule in your SAP. A mismatch here is the most common reason PFS outputs fail QC.

2. Derive the parameter

Pass the sources to the derivation, along with the start date (usually randomization):

adtte <- derive_param_tte(
  dataset_adsl = adsl,
  start_date = RANDDT,
  event_conditions = list(pd, death),
  censor_conditions = list(lastvisit),
  set_values_to = exprs(PARAMCD = "PFS")
)
VariableMeaning
AVALTime to event or censoring (days)
CNSR0 = event, 1 = censored
